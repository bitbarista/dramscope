DRAMSCOPE -- WHICH CHIP CARRIES WHICH BIT                 print me, keep me
(there is a nicer one-page A4 PDF of this in the release, if you can print it)
===========================================================================

DRAMscope names the failing DATA BIT, D0 to D7, and that bit number holds on
EVERY C64 ever made. WHICH CHIP CARRIES IT DOES NOT -- that depends on which
board you have, and translating one into the other is what this chart is for.


STEP 1 -- FIND YOUR ASSEMBLY NUMBER
-----------------------------------

Look for "ASSY" followed by six digits silkscreened on the board itself --
"ASSY 250469" or similar. THE POSITION VARIES BETWEEN REVISIONS, so scan the
whole board rather than one corner. Do not guess from the case or the badge:
the same case was used for several boards.


STEP 2 -- READ ACROSS
---------------------

  ASSY     BOARD   RAM          D0    D1    D2    D3    D4    D5    D6    D7
  -------------------------------------------------------------------------
  326298   long    8 x 4164     U21   U9    U22   U10   U23   U11   U24   U12
  250407   long    8 x 4164     U21   U9    U22   U10   U23   U11   U24   U12
  250425   long    8 x 4164     U21   U9    U22   U10   U23   U11   U24   U12
  250466   long    2 x 41464    <------ U10 ------>    <------ U9 ------->
  250469   short   2 x 41464    <------ U10 ------>    <------ U11 ------>

  Example: DRAMscope says D5 on a 250425  ->  replace U11.
           DRAMscope says D5 on a 250469  ->  replace U11 (it carries D4-D7).


*** BEFORE YOU DESOLDER ANYTHING ***

THE BIT IS MEASURED. THE CHIP IS A SUGGESTION -- which is why the screen says
LIKELY. What else could be at fault depends on HOW MANY BITS FAILED, and the
BITS row tells you that.

ONE BIT
  The fault is on that data line. The RAM is the likeliest part on it, but a
  dry or cracked joint, a corroded or spread socket contact, or a broken track
  to the CPU are INDISTINGUISHABLE to any software test.
  ⚠ The address and control logic CANNOT do this -- it is shared by all eight
  chips, so a fault there takes more than one bit with it.

FOUR BITS IN ONE NIBBLE, ON A TWO-CHIP BOARD
  Still one chip: a 41464 is four bits wide.

SEVERAL BITS, OR ALL EIGHT -- PROBABLY NOT A RAM CHIP AT ALL
  These are shared by the whole array, so one failure takes many bits at once:

    U13, U25    74LS257 address multiplexers
    U14, U26    74LS258 and 74LS373 -- VIC/CPU address switching
    RP1, RP2    330 ohm series packs on those lines
    U17         the PLA, which gates /CAS to the RAM
    VIC-II      generates RAS/CAS and the refresh

Work in this order, cheapest and most reversible first:

  1. Reseat the chip. Socketed RAM that has sat for forty years is a common
     fault all by itself.
  2. Inspect and reflow the joints on that chip and its socket.
  3. Check continuity along the data line, RAM pin to CPU pin.
  4. Only then swap the chip -- and keep the old one until the repair is
     confirmed, because it may well be good.

If you replace a chip and the same bit still fails, the chip was not the
fault. That is information, not a wasted part: it points at the line.

⚠ DRAMscope is offered with no warranty of any kind (see LICENSE). It tells
you what it measured. Deciding what to replace is yours.

WHAT THE SCREEN SHOWS
---------------------

   MEMORY FAULT, FIRST BAD BYTE AT $4037
   BITS                               D0
   LIKELY                             U21
   8X4164 ASSUMED. 41464? D0-D3=1 CHIP.

The row says LIKELY, not the chip's name as a fact. It is filled in for you
because all three 8 x 4164 boards are wired identically. If your board has only TWO RAM chips, ignore that row
and use this chart -- the tool cannot tell which board it is plugged into.


*** THE TWO 41464 BOARDS ARE THE OPPOSITE WAY ROUND FROM EACH OTHER ***

  250469   the LOWER number carries the LOWER bits   (U10 = D0-D3)
  250466   the LOWER number carries the UPPER bits   (U10 = D0-D3, U9 = D4-D7)

There is no rule to work this out from. Check the assembly number.


*** COUNTING THE CHIPS DOES NOT TELL YOU THE BOARD TYPE ***

250466 is a LONG board with two RAM chips. "Two chips means short board" is
wrong, and so is "long board means eight chips".


IF EVERY BIT FAILS
------------------

DRAMscope names no chip at all and says SEE PLA. Eight dead RAM chips is not
the likely reading -- suspect the PLA, the address multiplexers at U13/U25,
or their series resistor packs RP1/RP2. Sending you to desolder eight chips
would be worse than sending you nowhere.


COLOUR RAM IS NOT A DRAM
------------------------

If the screen says COLOUR RAM, that is a separate 1K x 4 static chip and none
of the above applies. It causes wrong colours rather than a crash, which is
why it gets blamed on the VIC. It is never counted against the DRAMs.
